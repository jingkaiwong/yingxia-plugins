# 映匣直播插件源（Yingxia Plugins）

用于 **映匣（Yingxia）** 的第三方直播插件源。目前提供斗鱼插件的登录入口兼容版本。

## 一键导入

在映匣中打开**插件源管理／添加插件源**，粘贴以下地址：

```text
https://raw.githubusercontent.com/jingkaiwong/yingxia-plugins/main/source.json
```

导入后安装或更新斗鱼插件，即可在映匣中使用。

## 已收录插件

| 平台 | 版本 | 说明 |
| --- | --- | --- |
| 斗鱼（Douyu） | 2.0.26（映匣适配测试版） | 在原版 2.0.25 基础上调整登录声明，以便映匣识别斗鱼登录入口 |

### 本次适配内容

原版斗鱼插件已包含账号登录及登录态取流相关实现，但在映匣中未显示登录入口。本仓库的适配改动主要是将插件登录声明中的：

```json
"auth": {
  "required": false
}
```

调整为：

```json
"auth": {
  "required": true
}
```

这里仅展示发生变化的字段，其他认证字段保持原样。原有分类、搜索、播放和弹幕等功能未有意改动。

> **说明：** 此版本已在实际使用中解决“映匣不显示斗鱼登录入口”的问题。`required: true` 是用于映匣兼容的登录入口声明，并不意味着斗鱼平台的所有公开内容都必须登录才能观看。实际登录流程及可用清晰度受映匣版本、斗鱼接口及账号权限影响。

## 注意事项

- 本项目是**非官方兼容适配**，与斗鱼、AngelLive、映匣官方无隶属关系。
- 登录后是否能够使用原画或其他高画质，取决于平台实际返回的画质档位及账号权限；本项目不提供会员权限绕过。
- 请尽量使用映匣内受信任的登录流程，不要在公开仓库、Issue 或聊天中分享 Cookie、Token、账号密码等敏感信息。
- 如果插件源无法导入，请先确认上述 `source.json` 链接可以正常访问，并检查网络连接与映匣版本。
